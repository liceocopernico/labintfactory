# Legacy: the Jupyter/ipywidgets `labintfactory` 0.1

The original notebook interfaces (photometer, magnetic field profile), kept only as a reference while their features are ported to LabDaemon. This code is not packaged, installed or tested. Its known bugs are listed in the design (`docs/design`, §9).

To use it as it was, check out the commit before the LabDaemon restructure (`d9c3654`).
